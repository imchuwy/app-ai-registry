# Third-party notices

The project source licence is pending. Third-party dependencies retain their own licences and copyright notices.

Runtime packages include React and React DOM (MIT), Zod (MIT), Lucide icons (ISC, with retained component notices), and the Inter and Manrope font families (SIL Open Font License 1.1). The installed package versions are pinned in `package-lock.json`.

Full notices for the runtime dependencies and fonts are distributed in `public/licenses/` and copied into the static build. Build and test tools retain their notices in their installed packages. The supplied OC AI branding is separate from these third-party packages; no project-wide open-source licence has yet been selected.
